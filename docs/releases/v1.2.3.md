# v1.2.3

## Highlights

- Adds temperature and humidity widgets for parent, viewer, and member roles.
- Adds parent/admin environment threshold automation rules for DHT11 sensors.
- Adds Cloud cron schedule triggers, validation, and minute-based execution.
- Adds Mobile schedule presets, custom five-field cron input, and direct Light targets.
- Adds a Light-only Scene picker contract and Gateway handoff.
- Audits Mobile English source copy and Vietnamese localization.
- Confirms Mobile QR provisioning no longer requests `install_code`; Cloud retains it as a server-owned secret.
- Aligns Mobile gateway status with the authenticated gateway status endpoint.

## Scene Dependency

Direct Light schedules are ready. Scene listing and activation require the Gateway/Cloud sibling implementation of `GET /api/scenes` and the MQTT contract in `docs/handoffs/gateway-light-scenes-contract.md`. Until then, Mobile falls back to direct Light selection.
