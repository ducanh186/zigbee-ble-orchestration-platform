# Firmware Artifacts

## Overview

All flashable firmware lives in `artifact/` at the repo root. Each device has its own subdirectory with a manifest, flashing instructions, and `.s37` binary files.

```
artifact/
  README.md
  bootloader-uart-xmodem/
    manifest.json
    FLASH.md
    bootloader-uart-xmodem.s37
    bootloader-uart-xmodem-crc.s37
    bootloader-uart-xmodem-combined.s37
  ncp-uart-hw/
    manifest.json
    FLASH.md
    ncp-uart-hw.s37
  Z3Switch/
    manifest.json
    FLASH.md
    Z3Switch.s37              
  Z3Light/
    manifest.json
    FLASH.md
    Z3Light.s37               
```

## What Was Removed from end_devices/ and Why

The following were removed from git tracking to reduce repo size and noise.
They are fully regenerated by Simplicity Studio when you open/build the `.slcp` project.

| Removed | Reason |
|---------|--------|
| `autogen/` | ~55 files per project, regenerated from `.slcp` + `config/zcl/zcl_config.zap` by SLC |
| `.pdm/` | Simplicity Studio internal module state |
| `.settings/` | Eclipse workspace preferences |
| `.uceditor/` | Component editor UI state |
| `.project` / `.cproject` | Eclipse CDT project descriptors; regenerated on import |
| `.projectlinkstore` | IDE navigation history |
| `*.zap~` | Backup files from ZAP configurator |

## What Is Still Tracked in end_devices/

| Kept | Purpose |
|------|---------|
| `*.slcp` | Project configuration — SDK version, components, device, board |
| `*.slps` | Project descriptor — toolchain ID, part ID, board IDs |
| `*.pintool` | Pin assignment configuration |
| `config/` | All component configuration headers + ZCL config (`.zap`) |
| `app.c`, `main.c`, `app/` | Application source code (custom logic) |

## Expected Binary Output Types

| Extension | Description | Use |
|-----------|-------------|-----|
| `.s37` | Motorola S-record | Primary flash image for Commander |
| `.hex` | Intel HEX | Alternative flash format |
| `.gbl` | GBL (Gecko Bootloader) | OTA firmware upgrade image |
